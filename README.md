# Dian Paramitha - Personal Portfolio

A modern, responsive, and performance-optimized personal portfolio web application built with **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Vite**.

## ✨ Features

- **Poorna-inspired Hero**: Interactive typewriter animation with dynamic blinking cursor and smooth entrance effects.
- **Fixed Glassmorphism Navigation**: Stays locked at the top during scrolling with quick access to social links (Email, GitHub, LinkedIn, Resume).
- **Modern Violet/Purple Aesthetic**: Harmonious color palette with luminous purple accents over deep navy background.
- **Asset Optimization**: Built with native lazy loading, asynchronous decoding, and responsive image scaling to prevent UI lag on image-heavy galleries.
- **Automated CI/CD**: Ready for zero-config GitHub Pages deployment via GitHub Actions.

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Bundler**: [Vite](https://vitejs.dev/)
- **Deployment**: [GitHub Pages](https://pages.github.com/) with GitHub Actions

## 🛠️ Getting Started Locally

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v20 or newer) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/<username>/<repo-name>.git
   cd <repo-name>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview the production build:
   ```bash
   npm run preview
   ```
